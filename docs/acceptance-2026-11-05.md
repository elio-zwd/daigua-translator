# 0.3.0 插件验证记录（2026-11-05）

本次更新针对“数据有效却无法判断是否加载”“未命中回退误译”和操作入口不便。保留 AI 原始 JSON，不修改 VS Code 用户／工作区配置，不自动安装插件，不控制电脑界面。

## 已确认的边界

- 本机可读的用户配置仍指向演示包，课程工作区可读设置只有 `mtrancode.multiLineMerge: false`。用户贴出的新路径配置与本次读到的文件不同；不能仅凭磁盘配置判定当前窗口的实际设置。新版诊断会显示扩展宿主实际读取的配置。
- 修订包包含 122 条，能通过插件的运行时校验并离线查询。`arg` 的正确说明原先只存在于 `worker.parameters`，旧插件不会查找该层级。
- MTranCode 可能在调用本插件前返回缓存；已有词典插件也可能显示自己的悬停译文。只看到“啊”等结果不能证明当前包是否加载。

## 本次改动

- 快捷设置和知识包文件选择，选错 manifest／review 等无效 JSON 时保留现有路径。
- 状态栏显示数量、Bing 状态及加载失败；诊断显示版本、包名、路径、用户／工作区配置、最近加载时间、有效数量和失败原因。
- Bing 开关及等待上限；关闭后不发起新请求，未命中／错误不作为成功翻译缓存。
- C/C++ 本地悬停及编辑器右键本地查询，两者不经过 MTranCode 缓存、不调用 Bing。
- 运行时从函数参数说明建立索引，显示所属函数。所有同名候选保留，暂不自动按当前位置消歧。
- 保存知识包后自动重载，250 毫秒合并连续文件事件；坏包仍保留上次有效内容。
- 按名称索引本地词条，快照变化后重建；合并相同内容和语言的在途 Bing 请求。

## 安装与手工检查

1. VS Code 扩展面板右上角 `…` → “从 VSIX 安装”，选择本次的 `plugin/daigua-translator-0.3.0.vsix`；之后运行“开发人员：重新加载窗口”。
2. 命令面板运行“呆瓜翻译器：选择知识包文件”，选择 `experiments/05-createtask-ai-direct-20261104-214840/pack-revised.json`。
3. 确认状态栏显示 122 条。点击状态栏，关闭 Bing 回退。
4. 打开课程 `src/main.c`，将鼠标移到 `interval`、`worker`、`arg` 上，确认“呆瓜 · 本地知识包”部分显示本地中文。`arg` 应显示 `worker` 的任务入参指针说明；其来源位置指向所属函数。
5. 编辑器右键“呆瓜翻译器：本地查询”，检查命中和来源；若状态不符，运行“查看加载诊断”读取实际生效路径和错误。MTranCode 原有悬停即使仍是旧译文，本地入口应反映当前加载包。
6. 在知识包的测试副本中修改一个说明并保存，确认自动重载；把副本临时改坏，确认旧内容保留及状态栏警告。不要用改动试验原稿的方式测试。

Bing 超时仅停止等待，底层库不支持取消在途请求；MTranCode 可能继续重试。本插件未清除宿主缓存，也不关闭其他翻译插件的网络行为。
