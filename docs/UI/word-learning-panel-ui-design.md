# 查词面板逐词学习：UI 设计

日期：2026-11-19。状态：0.7.0 界面实施规格。
适用对象：VS Code 固定查词面板。
目标环境：Windows 10 x64。

[功能设计](../Plan/word-learning-panel-functional-design.md)规定查询与数据行为。
本文规定视觉层级、组件、交互与界面验收。
实际截图和验证结果见 [0.7.0 验证记录](../acceptance-0.7.0-2026-11-19.md)。

## 2. 信息层级

视觉优先级从高到低：

- 完整英文名称、整名中文。
- 一句话用途、逐词中文与词段原文。
- 音标、缩写全称与原词中文。
- 解释类型、工程标签和推测标签。
- 使用提示与缺失提示。

「名称推测」须可读，不能弱化到无法辨认。
默认界面不显示文件路径、来源编号或错误堆栈。
整名用途不加入频率、引脚或完整参数表。
必要的类型宽度与单位必须保留。

有全称时，系统必须展示全称的可用信息。
缺失内容按第 8 节显示，不用占位示例文字。

## 4. 组件规格

### U01：工具栏

左侧显示「呆瓜 · 查词」。
右侧依次显示「跟随光标」「复制名称」「设置」。
工具栏固定在面板顶部，保留独立底边线。
滚动内容时，工具栏不遮挡首行内容。

「跟随光标」使用复选框语义。
勾选时，系统跟随光标查询。
取消勾选时，系统锁定当前结果。
锁定时增加文字状态「已锁定」。
状态不能只依赖颜色或图标。

该控件与现有锁定状态共用同一份数据。
禁止同时保留相反语义的两套锁定按钮。

「复制名称」复制完整原始名称。
复制成功后显示短提示「已复制名称」。
提示不打开模态窗口，也不挤动正文。
没有名称时禁用复制按钮。
「设置」打开现有设置页。

宽度不足时，品牌占第一行，操作区自然换到第二行。
按钮文字不省略为无法理解的孤立图标。

### U02：名称标题

英文名称使用编辑器等宽字体。
名称置于浅色底块，使用小圆角。
名称完整可选中，不使用省略号截断。
长名称优先在下划线边界换行。
没有分隔符时允许在任意字符间换行。
视觉换行不能向复制内容插入空格或换行。

英文标题为页面一级标题。
整名中文保持视觉突出，不让标签占据主标题位置。
顶部不显示完整音标长串。

### U03：整名释义卡

每个候选显示一张释义卡。
卡片内容为类型标签、工程标签、中文名和用途。
必要时增加所属函数。
单个候选无需显示「候选 1 / 1」。
多个候选显示「候选 1 / N」顺序提示。

本工程和其他工程参考分别显示自己的标签。
整名「名称推测」与逐词「名称推测」各自标记。

各卡片之间使用分隔线，不嵌套多层高亮背景。
旧包缺少用途时，中文名下方不保留空段落。
联网译文使用「联网翻译」标签。
纯逐词结果显示「词语释义」，不强行生成整名中文。

### U04：逐词理解区

区标题为「逐词理解」。
右侧提示为「词义帮助理解名称」。
区标题使用二级标题语义。
左侧允许使用细蓝色竖线，不能只靠竖线表达结构。
窄面板中提示换到下一行。

系统按名称顺序显示全部词段。
各词段之间使用细分隔线。
不使用卡片瀑布流或横向滚动。
学习区只出现一次，位于全部整名候选之后。
旧「名称补充」区的内容整合到对应词段。
禁止再重复渲染旧补充区。

### U05：词段行

词段行使用两列布局。
左列显示英文词段，可使用低对比度底块。
右列依次显示中文、音标、全称、原词信息和其余词义。
词段和中文位于同一视觉行，音标位于中文下方。
同一个词段的内容不能跨到其他词段行内。

中文主词义使用半粗体。
「名称推测」紧随推测中文，不使用实心警告大横幅。
推测分支包含全称时，分支内的全部信息受标签约束。
多义推测使用「可能含义 1」「可能含义 2」分组。
每个分组关联自己的全称和原词信息。

普通词典的跨领域义项标为「其他词典含义」。
这些义项直接展开，不混入技术缩写的主词义。

数字保留原始数字文字。
命名前缀显示规则中文，读音缺失时仍保留该词段。
单个词段的内容直接展开，不提供默认折叠按钮。

### U06：音标

音标与所属词段同组，使用次要文字颜色。
完整音标用一对 `/` 包围。
每个词段独占自己的音标行。

「拼字母」位于该行音标后方。
窄面板允许「拼字母」自然换行。
音标行不重复显示所属词段。
音标不使用斜体，以免影响音标字符辨认。

字体必须能显示 IPA 国际音标字符。
字体回退顺序包含 `Segoe UI` 和系统无衬线字体。

此规则只应用于固定面板。
悬停仍使用当前音标格式。

### U07：缩写全称与原词信息

缩写全称显示在本词段音标下方。
全称使用正常英文文本，不强制全部大写。
下方显示小标题「原词释义与读音」。
系统直接显示原词列表，不显示三角折叠箭头。

每个原词占一行组：

- 第一行：原词与中文主词义。
- 第二行：该原词的音标或缺失提示。
- 后续行：其余词义，若有则直接显示。

原词区使用轻微缩进或细左边线区分层级。
原词区不套用与主词段相同的大色块。
全称与原词列表之间无需重复打印英文全称。
禁止显示缩写音标作为整个英文全称的音标。

### U08：其余词义

其余词义位于所属词段或原词之下。
标题使用「其余词义」。
内容使用正文列表和次要字重。
全部词义直接可见，长文本自然换行。
没有其余词义时，不显示标题和空容器。

禁止只显示计数而隐藏真实词义。
词义多时允许整页变长，禁止默认截断。

### U09：底部提示与调试

有源码释义时，底部提示为：

> 拆词含义用于辅助理解，具体用途见上方源码释义。

没有源码释义时，底部提示为：

> 拆词含义用于辅助理解，不能据此确认代码实际用途。

推测词条仍必须显示自己的「名称推测」标签。
底部提示只显示一份。
调试信息遵守现有默认关闭开关。
调试区允许折叠，学习内容默认全展开的规则不涉及调试区。

## 5. 建议尺寸与排版

数值是实现起点，允许根据真实截图微调。
布局不能依赖参考图的固定分辨率。

| 元素 | 建议尺寸 |
| --- | --- |
| 正文字号 | 使用 `--vscode-font-size`，默认视觉基准 14 px |
| 英文名称 | 20 至 24 px，行高 1.4 |
| 整名中文 | 24 至 28 px，行高 1.4，字重 600 |
| 一句话用途 | 15 至 16 px，行高 1.7 |
| 区标题 | 17 至 18 px，字重 600 |
| 词段与主词义 | 15 至 16 px，字重 600 |
| 音标、全称、原词内容 | 13 至 14 px，行高 1.6 |
| 标签和底部提示 | 12 至 13 px，行高 1.6 |
| 内容最大宽度 | 760 px，居中 |
| 面板左右内边距 | 常规 20 至 28 px，窄面板 12 至 16 px |
| 区块上下间距 | 24 至 28 px |
| 词段行上下内边距 | 14 至 18 px |
| 词段内部间距 | 4 至 8 px |
| 词段左列宽度 | 常规 88 至 112 px |
| 两列间距 | 12 至 20 px |
| 轻背景圆角 | 4 至 6 px |
| 工具栏操作高度 | 不小于 28 px |

中文和英文名称都必须可辨认。
不能通过缩小音标到不可读来压缩高度。
用户缩放或字体变大时，组件应自然增高。

## 6. 响应式布局

| 面板可用宽度 | 布局行为 |
| --- | --- |
| 不小于 480 px | 词段两列，标题提示可并排 |
| 320 至 479 px | 保留两列，左列约 80 px，减小间距 |
| 小于 320 px | 词段改为上下布局，英文在上，中文与音标在下 |

宽度断点使用 Webview 内容宽度计算。
长词段不能把右列推出视口。
右列容器使用 `min-width: 0` 并允许换行。

原词行在窄面板中也改为上下布局。
工具栏换行后仍应完整可操作。
整个页面不能出现内容导致的横向滚动条。
调试路径和长错误文本也必须换行。

## 7. 主题与无障碍

颜色优先使用 VS Code 主题变量。
避免使用图片中的固定白底、黑底和灰色值。

| 用途 | 建议主题变量 |
| --- | --- |
| 页面背景 | `--vscode-editor-background` |
| 主要文字 | `--vscode-editor-foreground` |
| 次要文字 | `--vscode-descriptionForeground` |
| 轻背景 | `--vscode-textCodeBlock-background` |
| 分隔线 | `--vscode-panel-border` |
| 链接与小面积强调 | `--vscode-textLink-foreground` |
| 焦点轮廓 | `--vscode-focusBorder` |
| 高对比度边框 | `--vscode-contrastBorder`，需提供回退值 |

浅色、深色、高对比度深色和高对比度浅色均需检查。
常规文字对比度目标不小于 4.5:1。
大字号文字对比度目标不小于 3:1。
主题次要色不达目标时，应调整为主要文字色。

复选框和按钮使用真实可聚焦控件。
Tab 顺序按页面阅读顺序排列。
Space 切换跟随复选框，Enter 触发按钮。
焦点轮廓必须可见，不能只靠背景变化。

系统不添加没有动作的可点击词段底块。
标题、标签和词义具备可读的 DOM 文本。
图标需要文字标签或可访问名称。
加载状态使用温和的状态播报，避免重复打断阅读。
所有正文均可选择复制。

## 8. 状态与文案

| 状态 | 展示位置 | 文案及行为 |
| --- | --- | --- |
| 无查询 | 内容区 | 「读懂一个名称」及现有使用提示 |
| 学习数据加载中 | 学习区 | 「正在整理逐词释义…」，整名结果可读 |
| 学习数据失败 | 学习区 | 「逐词释义暂不可用」，详细错误仅在调试区 |
| 词义缺失 | 对应词段 | 「释义暂缺」 |
| 音标缺失 | 对应音标行 | 「音标暂缺」 |
| 原词部分缺音标 | 原词小标题 | 「原词释义与读音 · 部分音标暂缺」 |
| 原词全部缺音标 | 原词小标题下 | 「原词音标暂缺」，仍保留原词列表 |
| 逐词对齐失败 | 学习区提示 | 「部分读音无法逐词对应」 |
| 数字或未标注型号 | 对应词段 | 「未标注读音」 |
| 名称推测 | 对应中文或分支标题 | 「名称推测」 |
| 多义推测 | 对应词段 | 「名称推测 · 可能含义」并列候选 |
| 无完整名称释义 | 名称下方 | 「暂无完整名称释义，可查看逐词理解」 |
| 已锁定 | 工具栏 | 跟随未勾选，并显示「已锁定」 |
| 复制成功 | 工具栏状态区 | 「已复制名称」，不弹出模态窗口 |

缺失提示不使用错误红色大横幅。
词义缺失和音标缺失分别显示。
系统不能用一个「部分缺失」隐藏具体缺失位置。

## 9. 更新与阅读连续性

不同名称出现时，内容区回到顶部。
同一名称补充完成时，只更新需要变化的区块。
滚动位置、键盘焦点和文本选择应保持。
新请求不能复用旧名称的推测标签或原词列表。

锁定后，光标变化不能替换当前学习内容。
解锁后，工具栏与内容必须使用同一状态。
面板关闭后再次打开，使用现有面板生命周期规则。
本次不新增跨会话学习历史或滚动位置持久化。

## 10. 实施注意事项

面板 HTML 和样式应与悬停 Markdown 分开。
禁止直接修改公共音标文本函数导致悬停跟随变化。
旧「名称补充」内容应合入词段行，不重复显示。
HTML 字段必须转义，外部数据不能成为可执行代码。

继续保留 Webview 内容安全策略。
原词展开不需要从 Webview 直接访问文件或网络。
正文与设置页若共用样式，应限定新增选择器作用域。
禁止为查词面板样式破坏设置页布局。
参考图只属于文档，不应打包进插件运行资源。

## 12. 给接手 AI 的执行约束

先读取功能设计，再按本文实现面板。
用户最新选择优先于参考图中的折叠箭头。
只改固定面板，保持悬停现状。
将真实数据与推测数据分开标记。

运行时不要求用户配置 AI 或 API Key。
完成源码和词库工作后，再执行完整验证。
交付时明确区分规划、已实现功能和验证结果。
