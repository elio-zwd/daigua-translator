# extractor — 源码提取工具

从 MCU C/C++ 工程中提取函数、变量、宏等符号，生成中间 JSON 文件，供 AI 整理中文说明用。

## 待开发内容

- `extract.py` — 主入口，接收 `--src` 工程目录和 `--out` 输出目录
- 函数提取：名称、声明、参数、返回类型、已有注释、函数体、来源文件和行号
- 变量提取：全局/静态变量，名称、类型、已有注释、所在文件
- 宏/枚举/类型定义提取
- 过滤规则：构建产物目录（`build/`、`Debug/`、`Release/`）、重复声明、普通局部变量

## 输出格式

```
out/
├── functions.json
├── variables.json
├── macros.json
└── uncertain.json   # 提取不确定的内容
```

## 工具选型原则

以能正确处理目标工程为准。简单工程可用正则；复杂工程（宏展开、条件编译）考虑 libclang。  
不预先引入解析框架，待看到真实工程后决定。
