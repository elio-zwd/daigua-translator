# plugin — MTranCode 自定义翻译插件

作为 MTranCode 的自定义翻译服务，提供本地知识包查询能力，未命中时回退到 MTranCode 自带的 Bing 翻译。

## 待开发内容

开发前需先阅读 MTranCode 源码，确认：

1. 自定义翻译服务的接口格式（输入输出结构、注册方式）
2. 如何调用宿主自带的 Bing 翻译（回退方式、避免循环调用）
3. 插件配置项的存储位置（知识包路径、重新加载入口）

参考 `../MTranCode/`（已克隆）中的相关源码。

## 运行时流程

```
收到翻译请求
  │
  ▼
按匹配规则查询已加载的知识包
  │
  ├── 精确命中 ──→ 返回中文说明（不发起网络请求）
  │
  └── 未命中 ────→ 转交 MTranCode 自带 Bing 翻译
                        │
                        ├── Bing 成功 ──→ 返回译文（不写入知识包）
                        └── Bing 失败 ──→ 返回翻译失败提示
```

## 匹配规则

1. 精确匹配原始符号，保留大小写。
2. 忽略首尾空格；剥离函数名末尾空括号（`Motor_Start()` → 查询 `Motor_Start`）。
3. 同名词条存在歧义时，显示模块和来源，不自动选定。
4. 长文本无法完整匹配时，整段交给 Bing，不做部分替换。

## 插件配置

- 知识包路径（支持多个，按顺序查询）
- 重新加载知识包入口

不提供 API Key、模型或 AI 服务地址配置。
